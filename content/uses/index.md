## Development Tools

### Mobile Development

- [Android Studio](https://developer.android.com/studio) provides an editor, debugger, and emulator for Android apps.
- [Android Debug Bridge (adb)](https://developer.android.com/tools/adb) can install a build on a connected phone and stream its logs to the terminal.
- [Xcode](https://developer.apple.com/xcode/) builds and debugs apps for Apple platforms.

### Code Editors

- [Visual Studio Code](https://code.visualstudio.com/)
- [Zed](https://zed.dev/)

I previously used [Cursor](https://www.cursor.com/en), a code editor that suggests completions as you type and can edit multiple files from a prompt.

### Terminals

- [iTerm2](https://iterm2.com/) on my personal Mac.
- [Warp](https://www.warp.dev/)
- [cmux](https://cmux.com/) keeps terminal sessions in split panes and flags the ones that need input.

### Shell

On my personal Mac, I use [Zsh](https://www.zsh.org/) with [Oh My Zsh](https://ohmyz.sh/) for plugins and themes.

### Databases

- [DBeaver](https://dbeaver.io/) on my personal Mac.

### Containers

- [Rancher Desktop](https://rancherdesktop.io/) runs containers on macOS and includes a local Kubernetes cluster.

### Kubernetes

- [kubectl](https://kubernetes.io/docs/reference/kubectl/) is the command-line tool for inspecting and managing Kubernetes resources.
- [K9s](https://k9scli.io/) shows pods, logs, and other cluster resources in an interactive terminal view.

## AI Tools

### Coding Agents

- [Codex](https://openai.com/codex/) edits code in a repository, runs tests, and reviews changes.
- [Claude Code](https://claude.com/product/claude-code) works from the terminal to trace bugs, edit files, and run commands.
- [Kimi CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/guides/getting-started.html) brings Kimi into the terminal to read code, edit files, and run commands.
- [Pi](https://pi.dev/) is a terminal coding agent that can be customized with extensions.
- [OpenCode](https://opencode.ai/) is an open-source coding agent that lets you switch between model providers.

### Agent Workspaces

- [ZCode](https://zcode.z.ai/) provides a workspace for coding with GLM models and previewing the resulting app.
- [Orca](https://orca.dev/) runs coding agents in parallel, giving each one a separate Git worktree.
- [Herdr](https://herdr.dev/) organizes coding agents in terminal panes and shows which ones need input.
- [T3 Code](https://t3.codes/) brings conversations with coding agents and their code changes into one desktop app.

### Chat

- [ChatGPT](https://chatgpt.com/) answers questions, explains code, and helps draft text in a conversation.

### Local Model Runners

- [LM Studio](https://lmstudio.ai/) downloads and runs language models locally and can serve them through an API.
